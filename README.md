<h1>📊 First Innings Score Prediction Model — IPL T20 (Machine Learning Project)</h1>

<p>
This repository contains a machine learning model designed to predict the <strong>final first-innings score</strong> in IPL T20 cricket matches based on match context and real-time game progression.
</p>
<br>

<p>
Leveraging historical IPL data, the model analyzes scoring patterns and match conditions to estimate how many runs a team is likely to score by the end of their innings.
</p>
<br>

<p>
The project demonstrates the full lifecycle of a data science pipeline — from data collection to deployment-ready predictions — making it valuable for students, analysts, and cricket enthusiasts interested in sports analytics.
</p>
<br><br>

<h2>🔑 Key Objectives</h2>

<ul>
  <li>Predict the first-innings score using machine learning regression techniques.</li>
  <li>Understand how match factors influence scoring throughout an innings.</li>
  <li>Use features such as batting & bowling team, overs bowled, wickets lost, and run rate.</li>
  <li>Evaluate performance using standard regression metrics.</li>
</ul>
<br><br>

<h2>🏏 Dataset & Feature Engineering</h2>

<p>
The dataset includes historical IPL match records.
</p>
<br>

<p>
Preprocessing includes:
</p>

<ul>
  <li>Cleaning and formatting match statistics</li>
  <li>One-hot encoding for categorical variables</li>
  <li>Extracting overs, balls, current run rate, and wickets</li>
  <li>Removing irrelevant columns</li>
  <li>Creating regression-ready features</li>
</ul>
<br><br>

<h2>🧠 Model Architecture</h2>

<ul>
  <li>Linear Regression</li>
  <li>Random Forest Regressor</li>
  <li>Gradient Boosting</li>
  <li>Decision Tree Regressor</li>
</ul>

<p>
Models are evaluated using MAE, RMSE, and R² to measure predictive performance.
</p>
